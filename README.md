# 🚨 AI Emergency Response Assistant (RAG + Gemini API)

An end-to-end, production-ready Generative AI application that provides immediate, prioritized, step-by-step emergency guidance for life safety situations (fire, earthquake, flood, medical emergencies, CPR, severe bleeding).

The application uses **Retrieval-Augmented Generation (RAG)** to retrieve verified emergency response protocols from official documents and uses **Google Gemini** to generate clear, actionable response plans grounded in trusted sources.

---

## 🏗️ Architecture Overview

The system is designed with three clearly separated layers:

1. **Frontend Layer (React + Vite)**
   - Responsive, dark-mode emergency assistant UI.
   - Quick preset buttons for common emergencies (Fire, Earthquake, Flood, CPR, Bleeding).
   - Status indicators for real-time API health checks (`/health`).
   - Context snippet inspect accordion showing retrieved RAG chunks.
   - Configurable API endpoint via `VITE_API_BASE_URL`.

2. **Backend REST API Layer (Python + FastAPI)**
   - Asynchronous FastAPI server.
   - `/chat` endpoint processing emergency queries through RAG engine.
   - `/health` endpoint for monitoring backend & vector store status.
   - `/ingest` endpoint for triggering document chunking and embedding updates.
   - `/history` endpoint retrieving past emergency logs.
   - CORS middleware enabled for cross-origin frontend communication.

3. **Database & Vector Store Layer**
   - **ChromaDB**: Vector database storing document chunk embeddings generated by Google Gemini (`models/text-embedding-004`).
   - **SQLite**: Local database (`app.db`) storing query logs, timestamps, generated answers, and source citations.

## 🔑 Environment Variables Setup

1. Copy `.env.example` to `.env` in both root/backend and frontend:

```bash
# In backend/
cp .env.example .env

# In frontend/
cp .env.example .env
```

2. Set your Google Gemini API Key in `backend/.env`:

```env
GOOGLE_API_KEY=your_actual_gemini_api_key_here
CHROMA_DB_DIR=./chroma_db
DATA_DIR=../data
PORT=8000
ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000
```

3. Set your Backend URL in `frontend/.env`:

```env
VITE_API_BASE_URL=http://localhost:8000
```

## 🚀 Quick Start & Installation

### Prerequisites
- **Python 3.10+**
- **Node.js 18+** & **npm**
- **Google Gemini API Key** ([Get one here](https://aistudio.google.com/))

---

### Step 1: Run the Backend (Python FastAPI)

1. Open a terminal and navigate to `backend/`:
   ```bash
   cd backend
   ```

2. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Run initial Document Ingestion (Ingests text/PDF files into ChromaDB):
   ```bash
   python ingest.py
   ```

5. Start the FastAPI backend server:
   ```bash
   uvicorn main:app --reload --port 8000
   ```
   The backend API will run at `http://localhost:8000`. You can inspect interactive API documentation at `http://localhost:8000/docs`.

---

### Step 2: Run the Frontend (React + Vite)

1. Open a second terminal window and navigate to `frontend/`:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` in your browser.

## 📡 REST API Documentation

| Method | Endpoint | Description |
| text | text | text |
| `GET` | `/` | Root status and API metadata |
| `GET` | `/health` | Health check & vector store status |
| `POST` | `/chat` | Submit emergency query; returns RAG answer + source citations |
| `POST` | `/ingest` | Triggers document ingestion into ChromaDB |
| `GET` | `/history` | Fetches recent emergency logs from SQLite |

### Example Request (`POST /chat`)
```json
{
  "query": "A grease fire started on the stove, what do I do?"
}
```

### Example Response
```json
{
  "answer": "1. IMMEDIATE ACTION: Do NOT use water on a grease fire!\n2. Turn off the burner if safe.\n3. Cover the pan with a metal lid...",
  "sources": [
    "emergency_guide.txt"
  ],
  "snippets": [
    {
      "source": "emergency_guide.txt",
      "text": "If a grease fire occurs, smother it with a lid..."
    }
  ],
  "log_id": 1
}
```

## 🌐 Deployment Instructions

### Frontend Deployment (Vercel / Netlify)
1. Push project to GitHub.
2. Import the `frontend/` folder into Vercel or Netlify.
3. Set Environment Variable:
   - `VITE_API_BASE_URL` = `https://your-deployed-backend-url.onrender.com`
4. Deploy!

### Backend Deployment (Render / Railway / Fly.io)
1. Import the repository and set Root Directory to `backend`.
2. Build Command: `pip install -r requirements.txt && python ingest.py`
3. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. Set Environment Variables:
   - `GOOGLE_API_KEY` = your Gemini API Key
   - `ALLOWED_ORIGINS` = your frontend deployment URL
